🌿 SN Mehendi Online Order

SN Mehendi Online Order is a responsive web-based ordering application designed to make ordering mehendi cones simple, fast, and convenient. Customers can browse available mehendi products, select quantities, enter their personal details, and submit an order online.

✨ Features

- 🛍️ Browse available Mehendi cones
- ➕ Select multiple products and quantities
- 🧾 Automatic order summary and total calculation
- 👤 Customer name, phone number, and address form
- 📱 Mobile-friendly responsive design
- 🔔 Form validation and user-friendly notifications
- 📦 Simple online order submission
- 🎨 Clean and attractive mehendi-themed UI
- 📲 PWA-ready structure for mobile installation

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Progressive Web App (PWA)
- Web App Manifest
- Service Worker

🎯 Purpose

The project was created as a practical web application to provide a simple digital ordering experience for a mehendi business while improving accessibility for customers using mobile devices.
